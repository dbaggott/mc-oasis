Frequently asked questions

Will the sessions be moderated by an adult?

Yes.

We’ve never done anything like this before, so honestly, we’re figuring it out as we go. But we think it’s important to have adult moderation, and we’re hoping other adults will be willing to help.

Is there an age limit?

No.

However, you should know that this server runs in Survival mode, which means there are hostile creatures (zombies, skeletons, giant spiders, etc.) that will attack players.

Minecraft can also be played in Creative mode, where there’s no combat and the focus is purely on building. This server doesn’t use Creative mode. If you want to learn more about Creative vs. Survival and whether Survival is right for your kiddo, there’s plenty online to help you decide.

In addition, there are server rules that we recommend reading through to help you evaluate whether this server is a good match for your kid’s age and temperament.

If you don’t think your kid is ready for OASIS SMP yet, you are always welcome to sign them up later.

Is this an official school program?

No, this is not run by the school in any way. The OASIS staff were kind enough to help get the word out, but it’s not an official program, and it does not satisfy any curriculum requirements.

Our kiddo is passionate about Minecraft, and we know he’s not the only one. He wanted to create an OASIS Minecraft server, and… well, here we are!

Can my child use the school-provided Chromebook?

Probably not.

There are two parts to this: what the school allows and what’s technically possible. We don’t know the school’s policy on downloading apps onto a school Chromebook, but we suspect it’s not allowed and possibly even blocked. Technically, it might be possible with the Minecraft app for Chromebook, but that’s a paid app. Also, some schools provide Minecraft Education, but even if it’s present, it can’t connect to OASIS SMP. We don’t have Chromebooks and have no firsthand experience.

I’m on Bedrock and I’m worried most people will be on Java, or that Bedrock won’t work very well because it’s a Java server. Should I be?

Have no fear, there are plenty of Bedrock players! We are using GeyserMC so Bedrock players can join our Java server. GeyserMC is the standard way for Bedrock players to connect to Java servers, and the general consensus is that it works well. We are Java players, but we also have Bedrock accounts, and we can tell you firsthand that it works. There’s nothing extra you need to do unless you play on a console (Switch, Xbox, PlayStation, etc.): see the Play page.

If any issues are discovered, we’ll do our very best to iron them out! Did we mention we’ve never done anything like this before?

Is it true that there are a couple of “easter eggs” on the main homepage of this site?

Maybe. If there are, your kid might want to try to find them.
