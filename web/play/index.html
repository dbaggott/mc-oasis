Java & Bedrock

How to play

Once your child is approved, open Minecraft, add a server and enter the address below. Java and Bedrock players join the same world.

Java Edition · Multiplayer → Add Server

mc.oasis-smp.com

Bedrock Edition · Servers → Add Server · Port 19132

mc.oasis-smp.com

When it's on

The server is only on during scheduled sessions. Outside them, Minecraft will show it as unreachable.

Consoles

Xbox, PlayStation and Switch can't add a server by address yet. If your child plays on one, say so on the request form: it's how we know to set that up.
