How to play

Open Minecraft, add a server and paste the address below. Java and Bedrock players join the same world. On a console? See below.

The server is only available during scheduled sessions; at other times Minecraft will show it as unreachable.

Java Edition · Multiplayer → Add Server

mc.oasis-smp.com

Bedrock Edition · Servers → Add Server · Port 19132

mc.oasis-smp.com

On a console

A console (Xbox, PlayStation, Switch) can’t add a server by its address, so console players join through the server’s own Xbox account instead:

  1. Ask us for the server’s Xbox gamertag. We give it out privately rather than putting it on this site.
  2. In Minecraft on the console, add that gamertag as a friend. It accepts friend requests on its own while the server is running.
  3. During a scheduled session, the server shows up in Minecraft’s Friends tab as a world to join. Join it from there.

Being friends with the server’s account only lets your kid see the server. They still need to be let in, like every player.
