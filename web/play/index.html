How to play

The server is only available during scheduled sessions; at other times Minecraft will show it as unreachable. Do not forget to request access, all players must be added to the list of allowed gamers.

On a computer, phone or tablet

Open Minecraft, add a server and paste the address below.

Java Edition · Multiplayer → Add Server

mc.oasis-smp.com

Bedrock Edition · Servers → Add Server · Port 19132

mc.oasis-smp.com

On a console

A console (Xbox, PlayStation, Switch) can’t add a server by its address, you join by adding mc oasis school as a friend:

  1. In Minecraft on the console, add mc oasis school as a friend. Do not worry if the friend request is not immediately accepted. It will automatically get accepted the next time the server starts.
  2. During a scheduled session, the server shows up in Minecraft’s Friends tab as a world to join. Join it from there.
