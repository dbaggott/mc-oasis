The Un-Official Minecraft SMP Server for the Oasis School

The Oasis SMP Minecraft server hosts scheduled social sessions for families who participate in the Oasis School. The server is only available during scheduled sessions, and its goal is to create an inclusive environment that fosters collaboration, creativity, and social connection.

Server rules

Joining, once approved

Java Edition
Multiplayer → Add Server, with the address mc.oasis-smp.com
Bedrock Edition
Servers → Add Server, with the address mc.oasis-smp.com and port 19132

The server is only on during scheduled sessions. Xbox, PlayStation and Switch can't add a server by address yet: if your child plays on one, say so on the request form.
