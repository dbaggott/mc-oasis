About the server

  • Invite-only

    Only approved players can join. A parent requests access, and we add their child to the server's list by hand.

  • Java and Bedrock together

    Players on Java Edition and on Bedrock Edition join the same world, so friends can play together whichever one they have.

  • Looked after

    Chat is filtered, the rules below apply to everyone, and staff can step in when something goes wrong.

  • Voice chat is optional

    Java players who install the Simple Voice Chat mod can talk to players near them in the game. Nobody needs it to play.

The rules

The same rules players see in the game when they type /rules.

Joining

  1. Request access

    Fill in the request form with your child's Minecraft name and which edition they play.

  2. Wait for our email

    We add your child to the server by hand and write to you when they can join.

  3. Add the server in Minecraft

    Java Edition
    Multiplayer → Add Server, with the address mc.oasis-smp.com
    Bedrock Edition
    Servers → Add Server, with the address mc.oasis-smp.com and port 19132

    Xbox, PlayStation and Switch can't add a server by address. If your child plays on a console, say so on the request form: it's how we know to set that up.
