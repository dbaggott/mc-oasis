The Un-Official Minecraft SMP Server for the Oasis School

The Oasis SMP (Survival Multi-Player) Minecraft server hosts free social gaming sessions for families who participate in the Oasis School. The server is meant to support the Oasis educational program by creating an inclusive environment that fosters collaboration, creativity, kindness, and social connection. The server is only available during scheduled sessions.
