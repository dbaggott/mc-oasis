Before you join

A few things to set up ahead of your first session, so you can jump straight in. None of them are required to play.

Voice chat

The server runs Simple Voice Chat. With the mod installed, you hear players near you, up to 48 blocks away, and they hear you. Voice chat follows the same rules as text chat.

Voice chat works on Java Edition only. Bedrock players (phones, tablets, consoles and Windows Bedrock) can't use it, but can still play on the server as usual.

Install it

  1. Install the Fabric Loader for the version of Minecraft you play. Run the installer, pick your Minecraft version and click Install. The Minecraft Launcher now has a fabric-loader profile.
  2. Download Simple Voice Chat for Fabric, choosing the newest file for the same Minecraft version.
  3. Put the downloaded .jar file in your Minecraft folder's mods folder, creating the folder if it isn't there. In the launcher, open the fabric-loader installation's settings and click the folder icon to find the Minecraft folder.
  4. Start Minecraft from the fabric-loader profile and join the server.

If you already play with NeoForge, Forge or Quilt, use the Simple Voice Chat file for that loader instead. Lunar, Feather and other custom clients aren't supported by Simple Voice Chat.

On a Mac

macOS only lets an app use the microphone after asking you, and Minecraft started from the official launcher never asks, so nobody hears you. Starting Minecraft from Prism Launcher instead lets macOS ask. Simple Voice Chat's macOS guide has other ways.

First time in game

  1. When you join, a chat message says voice chat needs setting up. Press V to open the setup guide.
  2. Pick your microphone and speakers, then push-to-talk (you hold a key while you talk) or voice activation (your mic turns on when you speak). Push-to-talk keeps background noise out of everyone's ears.
  3. After that, V opens the voice chat menu. M mutes your microphone and N turns voice chat off and on. You can change any of these keys in Minecraft's Controls settings.

Talking to players far away

Join the Group VC group from the voice chat menu to talk with everyone in it, wherever they are in the world. You still hear players standing near you. Players can't make their own groups.
