# The WorldGuard regions in the overworld, set up by OasisRegions at every
# start, so the repo stays authoritative over them and a change made in game
# lasts only until the next start.
#
# Each region is a [name] line, then a `corners` line giving two opposite
# corners as x,y,z, then one `<flag> allow|deny` line per flag. A region that
# already exists gets these corners and flags and keeps its owners, members and
# any other flags. With no owners or members, only ops can build or break
# blocks in a region; the flags cover what membership doesn't.

# Spawn is on an island, and this covers all of it: the island runs x -504 to
# -437 and z 854 to 928, the region 8 blocks of water past that, from the
# bottom of the world to the top.
[spawn]
corners -512,-64,846 -429,319,936
pvp allow
mob-spawning deny
creeper-explosion deny
tnt deny
other-explosion deny
ghast-fireball deny
fire-spread deny
lava-fire deny
lighter deny
enderman-grief deny
use allow
chest-access allow
